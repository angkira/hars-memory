# Home-run tooling (written together with the implementation, 2026-10-26)

Goal: the owner runs the whole nc-eval at home (own HARS, real embedder, Anthropic key, later OpenRouter/Gemini via
profiles) and returns ONE bundle. Nothing here changes a metric or rule; Amendment C.2 (REPORT-PROTOCOL.md 4a.2) is the
only protocol text.

Decisions
- `scripts/home_run.py` is a Python orchestrator (not shell): stateful DAG over existing scripts, cost arithmetic from the
  runners' own dry-runs, JSON parsing, redaction scan, offline tests with a fake runner.
- One campaign dir per decision set under the artifact root (step markers, logs, exact command lines, spend ledger); resume =
  skip finished steps, `run_longsession --resume`, failed OH batch dirs moved aside never deleted; invalid (chain, B) cells
  retried and merged through "accepted views" so `merge_runs` sees one attempt per cell.
- Caps: gen / run / judge, hard, placeholders = refuse; each script gets `cap - spent`.
- providers.py is the single LLM/price layer for run_longsession, gen_longsession_qa, oh_pipeline (adapter), judge_v2.
- Long-session judging: export_longsession_judge.py + metrics_v2 long-session track (family L1-L5 on score, strata, lag).
- doctor has a behavioural semantic-recall probe because memory_status misreports the embedder for HTTP providers.

Out of scope / left: fixing hars_memory/mcp_server.py memory_status embedder line; calibrating HARS ingest s/piece;
live OH smoke (needs pi 1.4.x, not installable in the build container).
